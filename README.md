# CoMP project page

Anonymous research supplement for **Coherent Moment Propagation:
Epistemic Uncertainty for Pre-trained Robot Policies**.

## Preview

From this directory, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/. No build step or package installation is needed.

## Contents

- `index.html`: the project page.
- `static/css/` and `static/js/`: styles, interactive displays, and experiment measurements.
- `static/figures/` and `static/media/`: figures, videos, and images.
- `static/fonts/`: locally bundled font and its license.
